# 05. 아트 & 오디오 디렉션

## 비주얼 스타일
- **2.5D 사이드뷰 디오라마**, 깊이 레인 3개(앞/중/뒤) + 패럴랙스 하늘·폐허 스카이라인 2층.
- 스타일 후보: (A) 부드러운 픽셀아트 32~48px 캐릭터 (거지 키우기 계열, 제작 가장 빠름) / (B) 손그림 벡터·수채 느낌 (인스타 썸네일에 유리). **권장: A(픽셀) + 배경만 B(수채 그라디언트)** — 캐릭터는 양산이 쉽고 배경은 월페이퍼로 아름답다.
- 팔레트: 폐허의 회색·녹청(이끼)·녹슨 주황 + 따뜻한 조명(랜턴 노랑). 계절별 액센트(봄 연분홍, 여름 청록, 가을 주황, 겨울 남색).
- 금지: 네온, 강한 대비, 빠른 깜빡임(월페이퍼 피로도).

## 너구리 캐릭터 시트 (베이스 1벌)
| 애니메이션 | 프레임 | 용도 |
|---|---|---|
| idle | 4 | 멍 때리기(기본), 눈 깜빡임 |
| walk | 6 | 이동 |
| sit | 2 | 벤치/같이 앉기 |
| sleep | 2 | 숨숨집/낮잠, Zz 파티클 |
| shake | 4 | 나무 흔들기, 물 털기 |
| interact_a / interact_b | 4+4 | 인사·털 고르기 등 2마리 상호작용 (좌우 대칭 짝) |
| happy / sulk | 2+2 | 쓰다듬기 반응, 다툼 |
합계 약 34프레임 × 1벌. 색상 변형은 팔레트 스왑, 무늬·체형은 오버레이 레이어(각 4~8장). 스킨은 슬롯별 오버레이 + `anchors.json`.

### 라쿤 vs 한국 너구리 (10-open-questions #1)
- 라쿤: 검은 눈 마스크, 줄무늬 꼬리 → 실루엣 식별력 최상, 썬글라스 스킨이 "마스크 위에 또 마스크"라 웃김.
- 한국 너구리: 둥근 얼굴, 짧은 꼬리, 볼 털 → 더 한국적·토속적, "너구리 마을"이라는 제목과 정합. 꼬리 줄무늬 파라미터 대신 "볼 털 모양"으로 교체.

## 아티팩트/배경 에셋 목록 (MVP)
숨숨집(3단계), 나무(4계절 × 3성장), 우물, 벤치, 랜턴, 터널 입구, 폐허 스카이라인(패럴랙스 2장), 하늘 그라디언트(시간대 4 × 계절 4 = 16, 코드로 보간해 실제 파일은 색상표), 파티클(낙엽·눈·비·반딧불·벚꽃), UI 아이콘 20종, 스킨 초기 8종(썬글라스, 솜사탕, 목도리, 꽃, 안전모, 랜턴, 리본, 배낭).

## 제작 도구 파이프라인
| 단계 | 도구 | 비고 |
|---|---|---|
| 컨셉/무드보드 | Adobe Firefly Boards (이 환경의 Adobe MCP) 또는 Pinterest | 세션 밖에서 해도 됨 |
| 캐릭터 픽셀아트 | Aseprite(유료, 표준) 또는 LibreSprite(무료) | 태그별 내보내기 스크립트 → `assets/sprites/raccoon.json` |
| AI 초안 | **SpriteCook 플러그인**(스프라이트·타일셋·UI킷 생성, Godot 반입 스킬 포함) | 초안용. 최종은 손으로 정리해 일관성 확보 |
| 배경/수채 | Procreate / Krita / Firefly 이미지 생성 → 후처리 | 월페이퍼용 고해상도 2배 |
| 마케팅 이미지 | Adobe Express MCP(`create_visual_design_express_skill`) | 인스타 1080×1350 템플릿 |
| 스크린샷/GIF | Playwright 스크립트(`tests/capture/*.ts`) | 데브로그 자동 캡처 |

저작권: AI 생성물은 초안/참고로만, 최종 에셋은 수정·재작업해 스타일 일관성 확보. 특정 작가 스타일 모방 프롬프트 금지.

## 오디오 (ASMR BGM)
### 사운드 철학
"들리는지 모를 정도"가 정답. 음악은 기본 OFF, 앰비언스가 주인공.

### 레이어 설계
| 레이어 | 소스 | 변화 조건 |
|---|---|---|
| 바람 | 2분 루프 × 3(봄/가을 잔잔, 여름 잎 소리, 겨울 휘파람) | 계절 |
| 벌레/새 | 귀뚜라미(가을 밤), 매미(여름 낮), 참새(봄 아침), 올빼미(밤) | 계절 × 시간대 |
| 물 | 우물 물방울, 빗소리(약/강) | 우물 건설, 날씨 |
| 생활음 | 발걸음(흙/낙엽/눈 3종), 나무 흔들림, 숨숨집 삐걱, 너굴어 보이스(짧은 "뀨/뀨르" 3~5종, 피치 랜덤) | 행동 |
| 음악(선택) | 로파이 피아노 2~3곡, 템포 60~70 BPM | 사용자 ON 시, 밤에는 더 느린 곡 |
| 기념일 | 풍경(설), 방울(크리스마스) 등 1~2개 | 날짜 |

### 소스/제작
- 직접 녹음(가장 좋음: 폰 + 바람막이, 공원/우물/낙엽) → 인스타 비하인드 콘텐츠로도 활용.
- freesound.org CC0만 사용(CC-BY는 크레딧 관리 필요).
- 음악은 작곡 의뢰 또는 Suno/Udio 생성 후 상업 라이선스 확인(Social Media Skills 플러그인에 `suno`, `ai-music-and-sound` 스킬 있음).
- 마스터링: 모든 파일 -18 LUFS, 페이드 인/아웃 200ms 이상, OGG + M4A(iOS 호환) 이중 포맷.

### 접근성
- 소리 없이도 모든 정보 전달(아이콘 풍선). 청각 민감 사용자를 위해 레이어별 볼륨 슬라이더.
