# 03. 게임플레이 설계

## 코어 루프
```
[너구리가 알아서 산다] → [나뭇잎/도토리/반짝이 등 '자원'이 쌓인다]
      ↑                                      ↓
[새 너구리 합류 · 스토리 단서]  ←  [아티팩트 건설 · 스킨 장착]
```
- 플레이어 입력은 "탭해서 쓰다듬기", "아티팩트 배치", "스킨 입히기", "놀러가기" 네 가지뿐. 나머지는 자율.
- 방치 보상은 오프라인 최대 8시간까지 누적(거지 키우기 방식). 복귀 시 너구리가 모아둔 걸 "들고 와서" 보여준다 — 숫자 팝업이 아니라 연출로.

## 자원 (3종, 더 늘리지 않음)
| 자원 | 얻는 법 | 쓰는 곳 |
|---|---|---|
| 도토리 | 너구리가 나무에서 주움 (방치) | 아티팩트 건설 |
| 반짝이(유리 조각 등) | 우물·터널에서 발굴 | 스킨 제작/해금 |
| 마음(하트) | 쓰다듬기, 너구리끼리 상호작용 | 새 너구리 초대, 스토리 챕터 진행 |

## 주민(Resident) 시스템
모든 주민은 같은 `Resident` 엔티티이고 `species`(너구리·산짐승 24종·사람)만 다르다. 욕구·성격·관계·상호작용 로직은 종족 공통이며, 종족은 스프라이트 세트·걷는 속도·선호 아티팩트·말소리만 바꾼다. 너구리가 주인공이자 다수(마을의 60% 이상 유지), 챕터 2부터 산짐승이 랜덤으로, 챕터 3부터 사람이 합류.

### 너구리 다양성: 현실 종 + 현실 털색만, 파라미터로 곱한다
너구리는 **현실에 존재하는 종과 색만** 쓴다. 종 수는 적지만 **한 개의 베이스 리그에 파라미터를 곱하면** 수천 마리가 서로 다르게 보인다.

| 축 | 값 예시 | 개수 |
|---|---|---|
| 종 | 아메리카너구리(기본), 게잡이너구리(날씬·짧은 털), 코수멜너구리(소형·금빛 꼬리) | 3 |
| 털 팔레트(실제 색 변이) | 회색, 갈색, 계피색, 금발(blonde), 흑색증(검정), 백색증(흰색) | 6 |
| 얼굴 무늬 | 기본 마스크, 넓은 마스크, 외눈 마스크, 마스크 없음 | 4 |
| 꼬리 줄무늬 | 3줄, 5줄, 7줄, 무지 | 4 |
| 체형 | 통통, 보통, 길쭉, 작음(아기) | 4 |
| 성격(심즈식 특성 2개) | 느긋, 호기심, 겁쟁이, 먹보, 수다쟁이, 몽상가, 청결, 밤형 | 8C2 = 28 |
| 액세서리(스킨) | 썬글라스, 솜사탕, 목도리, 꽃, 안전모… | 확장형 |

3 × 6 × 4 × 4 × 4 × 28 = **32,256 조합** (스킨 제외). 전부 현실에 있을 법한 외형이다. 스프라이트는 **베이스 1벌 + 팔레트 스왑 + 오버레이 레이어**로 구현하므로 아트 비용은 "1마리 + 레이어 몇 장"이다.

> M2a 구현: 성격을 뺀 외형 축(털색 6 × 종 3 × 얼굴 무늬 4 × 꼬리 줄무늬 4 × 체형 4)이 **1152 변형**이다. 성격 28은 M2b.

> 확정: 기본 종은 라쿤(아메리카너구리). 한국 너구리(개과)는 너구리 파라미터가 아니라 **별도 종족**(`korean-raccoon-dog`, `quad-s`)으로 챕터 2부터 다른 산짐승처럼 합류할 수 있다.

### 다른 종족 (산짐승 24 + 사람, M2a 데이터 완료)
종족 목록은 `data/sprites/species.json`. 리그(뼈대) 6종을 종족들이 나눠 쓴다. 프레임은 리그당 14(idle 4 · walk 6 · sit 2 · sleep 2).
| 리그 | 캔버스(px) | 종족 |
|---|---|---|
| `raccoon` | 32×32 | 너구리(라쿤) — 주인공, 파라메트릭 변형 1152 |
| `quad-s` | 32×32 | 한국너구리, 여우, 삵, 담비, 오소리, 족제비, 수달, 멧토끼, 다람쥐, 청설모, 고슴도치, 두더지 (12) |
| `quad-l` | 48×40 | 반달가슴곰, 멧돼지, 산양 |
| `quad-deer` | 48×40 | 고라니, 노루 |
| `bird` | 24×24 | 까마귀, 까치, 수리부엉이, 딱따구리, 어치, 꿩 |
| `biped` | 24×40 | 사람 — 피부 4 × 나이대 3 × 머리 4 × 체형 3 = 144 변형 |
사람: 너구리와 같은 속도, 명령·사육 기능 없음. 곰: 느림, 위협 없음.
모든 종족은 같은 자원·같은 욕구·같은 상호작용 풀을 쓴다. 종족 간 상호작용에 보너스/페널티 없음(기둥: 구분 없음).

### 욕구 (심즈 축소판, 4개만)
배고픔 · 졸림 · 심심함 · 외로움. 게이지는 UI에 숫자로 안 보여주고 **행동과 생각 풍선**으로만 드러난다. (예: 외로움 ↑ → 다른 너구리 옆에 가서 앉음)

### 자율 행동 (Utility AI, 가중치 기반)
걷기 / 앉기 / 자기(sleep) / 나무 흔들기 / 우물 들여다보기 / 숨숨집 들어가기 / 다른 주민에게 다가가기 / 아티팩트 구경 / 멍 때리기(가장 자주). 종족별 가중치만 다르다(곰은 앉기·자기 ↑, 사람은 아티팩트 구경 ↑).
**야행성 종족**은 낮·밤 가중치가 뒤집힌다(밤에 걷기 ↑, 낮에 자기 ↑): 너구리, 오소리, 족제비, 삵, 고슴도치, 두더지, 담비, 멧돼지, 수리부엉이.
"멍 때리기"가 기본값이어야 월페이퍼가 산만하지 않다.

## 주민끼리의 상호작용과 언어 (하이브리드, 확정)
| 레이어 | 형태 | 보이는 조건 | 목적 |
|---|---|---|---|
| **종족어 말풍선** | 너구리 "너굴너굴?", 곰 "크릉…", 사람 "ㅇ…아…"(글자가 깨진 중얼거림). 글자 수·물음표·말줄임표로 감정 표현 | 두 주민이 가까이 있을 때 | 심즈어처럼 귀엽고 번역 불필요(현지화 비용 0). 종족이 달라도 대충 통한다 |
| **속마음(생각 풍선)** | 모든 종족 한국어 한 줄. "저 녀석 꼬리 멋있다." / 곰 "담이 있던 자리엔 바람이 분다." | 탭하거나 월페이퍼에서 가끔 자동 | 성격·관계·세계관 단서 전달 |
| **아이콘 풍선** | 🍂 💤 ❤ ? 같은 그림 | 항상 | 글 없이도 상황 전달 (롤러코스터 타이쿤 방식) |
| **번역 자막(해금 후)** | 종족어 밑에 작은 한국어: "너굴너굴? (밥 먹었어?)" / "크릉… (졸려.)" | 번역기 아티팩트 챕터 이후 | 성장감 + 스토리 장치. 모든 종족에 동일 적용 |

상호작용 종류(초기 8개): 인사 / 수다 / 같이 앉기 / 꼬리 잡기 놀이 / 도토리 나눠주기 / 서로 털 고르기 / 다툼(가볍게, 등 돌리기) / 화해. 관계도(친구·단짝·서먹)는 상호작용 누적으로 변한다.

대사 데이터는 `data/dialogue/*.json`으로 분리하고, 성격 태그별 풀에서 뽑는다. 속마음 문장은 수백 개가 필요하므로 **LLM으로 대량 초안 → 사람이 톤 검수** 파이프라인을 06 문서에 둔다.

## 스킨
- 슬롯: 머리(썬글라스, 꽃, 안전모) / 손(솜사탕, 랜턴) / 목(목도리, 리본) / 등(배낭)
- 각 스킨은 **아티팩트 설정과 연결**: 썬글라스 = "눈을 가리는 검은 유리", 솜사탕 = "먹을 수 있는 구름". 도감 설명이 곧 세계관.
- 구현: 베이스 스프라이트 위에 오버레이 레이어. 애니메이션 프레임별 앵커 포인트 JSON으로 위치 지정.

## 아티팩트 (건설물)
| 아티팩트 | 기능 | 세계관 |
|---|---|---|
| 숨숨집 | 주민 수용 +1, 졸림 해소 (곰은 큰 숨숨집 2단계 필요) | 폐허가 된 집의 남은 방, 쓰러진 나무 속 |
| 나무 | 도토리 생산, 그늘(여름 더위 완화) | 이끼 덮인 참나무, 폐가 지붕을 뚫고 자란 나무 |
| 우물 | 반짝이 발굴, 물소리 ASMR 레이어 해금 | 지하철 환기구에 고인 물 |
| 벤치 | 같이 앉기 상호작용 확률 ↑ | 인간이 남긴 그대로 |
| 전봇대 랜턴 | 밤 조명(월페이퍼 야경) | 아직 전기가 조금 남은 가로등 |
| 터널 입구 | 놀러가기/환승역 진입 | 챕터 5 해금 |

배치: 사이드뷰 디오라마의 **깊이 레인 3개(앞/중/뒤)** × 가로 슬롯. 격자가 아니라 "슬롯에 놓기"라서 모바일에서 드래그가 쉽다.

## 날짜 데이터 → 배경 반영
| 입력 | 소스 | 반영 |
|---|---|---|
| 시간대 | 기기 시계 | 새벽/낮/노을/밤 조명 + 하늘 그라디언트 + 너구리 활동량(밤형 성격은 밤에 활발) |
| 계절 | 날짜 → 4계절 (한국 기준; 설정에서 남반구 반전) | 나무 잎 색/낙엽/눈, 입김, 솜사탕 녹음(여름) |
| 절기(선택) | 날짜 → 24절기 테이블 | 속마음 한 줄 이벤트 ("오늘은 낮이 제일 길대") |
| 기념일 | 날짜 테이블(설/추석은 음력 변환 라이브러리) | 장식 아티팩트 임시 등장, 특수 상호작용 |
| 날씨(선택) | Open-Meteo API (무료, 키 불필요, 위치 권한 필요) | 비/눈/안개 파티클 + 빗소리 레이어. 월페이퍼 모드에서만 기본 ON |
| 보름달 | 날짜 → 월령 계산 | 밤 밝기, 너구리들이 모여 달 구경 |

오프라인이면 시계만 쓴다. 시계 조작(치트)은 막지 않는다 — 힐링 게임이라 경쟁 요소가 없다.

## 놀러가기 & 만남의 공간
- **마을 이름 = "<닉네임>의 디스토피아"**. 닉네임은 이 게임의 **유일한 자유 텍스트 입력**이다(최대 8자, 금칙어 필터, 변경은 7일에 1회). 월페이퍼 URL은 `/w/<공개ID>`를 유지하고 닉네임은 화면 간판에만 표시한다(URL에 닉네임을 쓰면 변경·중복 문제가 생긴다).
- **MVP(비동기)**: 친구 코드 입력 → 상대 마을 스냅샷(JSON)을 받아 내 클라이언트에서 재생. 내 너구리 한 마리가 터널로 들어가 상대 마을에 "손님"으로 나타난다. 상대에게는 다음 접속 때 "OO가 다녀갔어요" + 선물(도토리 소량).
- **후속(실시간)**: 환승역에서 Supabase Realtime presence로 같은 시간대 방문자들의 너구리가 함께 보인다. 채팅 없음, 너굴어 말풍선과 방명록 한 줄(사전 검수된 문구 선택식)만.
- 안전: 방명록은 선택식 문구. 자유 텍스트는 닉네임 하나뿐이므로 금칙어 필터 + 신고 버튼(신고 누적 시 '이름 없는 디스토피아'로 임시 표시)으로 충분하다.

## 월페이퍼 모드 (PC)
- `/w/<공개ID>`: 로그인 없이 내 마을을 읽기 전용으로 본다. 입력 없음, UI 없음, 소리는 클릭 한 번으로 켜기(브라우저 자동재생 정책).
- 저전력: 탭 비활성 시 일시정지, 활성 시 30fps 캡, 파티클 상한.
- 반응형: 16:9~21:9 가로에서는 디오라마 전체, 세로(폰 브라우저)에서는 중앙 레인 중심으로 카메라 팬.
- 1시간마다 서버에서 최신 스냅샷을 가져와 모바일에서 한 변화가 반영된다.

## 진행/해금 (압박 없는 progression)
- 챕터 진행 조건은 02 문서 표와 같다. 시간 제한·실패 조건 없음.
- 주민 합류: "마음" 자원으로 초대 → 터널에서 새 주민이 랜덤 파라미터로 등장. 챕터 1까지는 너구리만, 챕터 2부터 랜덤 산짐승, 챕터 3부터 사람이 섞인다(너구리 비율 60% 이상 유지). 플레이어가 이름을 짓는다.
- 도감: 아티팩트 / 스킨 / 속마음 명대사 수집.
