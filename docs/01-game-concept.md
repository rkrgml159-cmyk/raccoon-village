# 01. 게임 컨셉

## 제목
- 가제: **너구리 마을** (영문: *Raccoon Village*)
- 후보: 「너굴마을」, 「조용한 마을의 너구리들」, 「너굴너굴」 — 스토어/인스타 핸들 중복 확인 후 확정 (10-open-questions 참조)

## 장르 / 포지셔닝
**힐링 방치형 생활 시뮬레이션** (idle × life-sim × light tycoon)

| 레퍼런스 | 가져올 것 | 버릴 것 |
|---|---|---|
| 거지 키우기 | 방치 수익, 사이드뷰, 짧은 세션, 한 손 조작, 터치 보상 | 과도한 광고, 숫자 인플레이션 |
| 롤러코스터 타이쿤 | 손님(너구리)이 돌아다니며 시설(아티팩트)을 쓰는 걸 "구경"하는 재미, 생각 풍선 | 복잡한 경제, 경영 압박 |
| 심즈 | 욕구 게이지, 성격 특성, 관계도, 심즈어(Simlish)식 언어, 자율 행동 | 마이크로 매니지먼트, 생활 피로감 |
| Stray / Girls' Last Tour / 나우시카 | 인간이 사라진 뒤의 고요한 폐허 분위기 | 어두운 공포, 전투 |

## 핵심 기둥 (Design Pillars) — 모든 결정의 기준
1. **구경만 해도 좋다.** 아무것도 안 눌러도 너구리들이 알아서 살아간다. 월페이퍼 모드는 이 기둥의 극단.
2. **살아있는 시간.** 실제 날짜·시간·계절이 화면에 그대로 반영된다. 밤에 켜면 밤이다.
3. **작은 서사.** 디스토피아의 비밀은 너구리들의 속마음과 발굴한 아티팩트를 통해 조금씩 드러난다. 설명하지 않고 보여준다.
4. **귀에 편하다.** 모든 소리는 ASMR 기준. 깜짝 효과음·알림음 금지.
5. **남과 비교하지 않는다.** 랭킹 없음. 놀러가기는 자랑이 아니라 방문이다.

## 타깃
- 1차: 20~30대, 힐링/방치형/동물 콘텐츠 소비층, 인스타·릴스 유입
- 2차: PC 작업 중 "배경으로 띄워놓을 것"을 찾는 사용자 (월페이퍼 URL)
- 세션 길이: 모바일 1~3분 × 하루 여러 번, PC 월페이퍼는 수 시간 방치

## 플랫폼
| 플랫폼 | 형태 | 비고 |
|---|---|---|
| Android / iOS | 네이티브 앱(Capacitor 래핑) | 스토어 배포, 푸시 알림, 오프라인 저장 |
| PC 브라우저 | 웹 URL (`/play`) | 동일 계정으로 모바일과 동기화 |
| PC 월페이퍼 | 읽기 전용 URL (`/w/<공개ID>`) | 저전력 모드, Lively Wallpaper(Windows)/Plash(macOS)에 URL 등록 가능 |

## 수익화 (MVP에서는 보류, 설계상 메모)
- 코스메틱 스킨 팩(썬글라스, 솜사탕 등)만 유료. 능력치 판매 없음.
- 광고 없음(기둥 4·5와 충돌). 후원형 "너구리에게 간식 주기" 정도 검토.

## 성공 기준 (MVP)
- 월페이퍼 URL을 하루 종일 켜 둬도 CPU 점유 낮고 불쾌하지 않다.
- 처음 보는 사람이 설명 없이 30초 안에 "아 너구리들이 살고 있구나"를 이해한다.
- 인스타 릴스 15초 클립 한 개로 게임이 설명된다.
