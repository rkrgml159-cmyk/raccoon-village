# 10. 열린 질문 — 사용자 결정 필요

2026-11-03 기준 **모든 질문이 확정**되었다(1~4번은 선택 답변, 5~10번은 권장안 채택). 기록은 `docs/decisions.md`.

## 1. 라쿤인가, 한국 너구리인가? — ✅ 확정: 라쿤 기본, 현실 종(게잡이·코수멜)만 추가, 한국 너구리는 별도 종족으로 확장 가능 (2026-11-03)
- 한국어 "너구리"는 개과의 너구리(raccoon dog). 썬글라스·"쓰레기 판다" 이미지는 라쿤(미국너구리).
- **권장: 라쿤.** 눈 마스크·줄무늬 꼬리가 작은 스프라이트에서도 식별되고, 썬글라스 스킨이 "마스크 위 마스크"로 웃기며, 해외 해시태그(#raccoon)가 훨씬 크다. 제목은 그대로 "너구리 마을"을 써도 된다(한국 대중은 라쿤도 너구리라 부른다).
- 대안: 한국 너구리 → 토속적 정서, 국내 차별화. 꼬리 줄무늬 파라미터를 볼 털 모양으로 교체.

## 2. 너구리 종류가 적어서 여러 마리 만들기 힘든가? — ✅ 확정: 파라메트릭 변형. **변이 너구리는 취소, 현실 종·현실 색만** (2026-11-03 개정)
- 메모에서 "힘들면 질문하라"고 하셨는데, **결론은 힘들지 않다.** 종을 늘리지 않고 파라메트릭 변형(털색 7 × 무늬 4 × 꼬리 4 × 체형 4 × 성격 28 = 12,544 조합)으로 해결했다(03 문서). 아트는 베이스 1벌 + 오버레이 레이어.
- 다만 확인 질문: **디스토피아 설정상 "변이 너구리"(발광 꼬리, 푸른 털 등 비현실 색)도 허용할까?** 권장: 챕터 4 이후 희귀 등장으로 허용(수집 재미 + 세계관 단서). 거부하면 현실 색만 사용.

## 3. 상호작용 언어 — ✅ 확정: 하이브리드 (2026-11-03)
- 권장: **너굴어 말풍선 + 한국어 속마음 + 아이콘, 번역기 아티팩트로 점진 해석** (03 문서 하이브리드).
- 확인: 속마음 문장의 분량·톤. "한 줄 20자 내외, 담담한 반말" 권장. 존댓말/캐릭터별 말투 차등을 원하면 대사 데이터 규모가 2배가 된다.

## 4. "만남의 공간" 설정 — ✅ 확정 (2026-11-03)
- 같은 지구, 같은 폐허 도시의 다른 구역, 폐지하철 환승역에서 만남(02 문서). 설정 오류 아님.
- OOO = **플레이어 닉네임**. 마을 이름은 "<닉네임>의 디스토피아"로 확정, 환승역 표지판·방문 간판에 표시(02·03 문서 반영). 닉네임은 유일한 자유 텍스트이므로 금칙어 필터·신고 기능을 M4에 포함.

## 5. 제목/핸들 — ✅ 확정: 가제 '너구리 마을 / Raccoon Village' 유지, 핸들 중복 시 raccoonvillage.app 형태 (2026-11-03)
- 후보: 너구리 마을 / 너굴마을 / 너굴너굴 / 조용한 마을의 너구리들. 인스타 핸들·스토어명 중복 확인 후 확정. 권장: 가제 "너구리 마을" 유지, 영문 "Raccoon Village" 핸들 중복 시 "raccoonvillage.app" 형태.

## 6. 엔진 확정 — ✅ 확정: Phaser 4 + TS + Capacitor + Supabase (2026-11-03)
- 권장: Phaser 4 + TypeScript + Capacitor + Supabase (04 문서). 반대하면 Godot 4(차선). Unity/Unreal/Tripo/Blender는 제외 사유 있음.
- 확인: Godot 에디터처럼 "눈으로 배치하는 도구"를 꼭 원하는지. 원하면 Phaser에서도 레벨 데이터는 Tiled/LDtk(무료)로 편집 가능.

## 7. 아트 제작 주체 — ✅ 확정: 베이스 너구리 1벌은 직접/외주, 배경·아티팩트는 AI 초안 + 수정 (2026-11-03)
- 직접 그리는가, AI 초안 + 수정인가, 외주인가? 권장: 베이스 너구리 1벌은 외주 또는 직접(일관성), 배경·아티팩트는 AI 초안 + 수정. 예산이 있으면 알려주면 로드맵 조정.

## 8. 수익화 — ✅ 확정: 코스메틱 스킨 팩만, 광고 없음, M5에 IAP 포함 (2026-11-03)
- 권장: 코스메틱 스킨 팩만, 광고 없음. 동의하면 M5에 결제(Capacitor In-App Purchase) 포함, 아니면 무료 출시 후 결정.

## 9. 인스타 계정 — ✅ 확정: 사용자가 직접 Business/Creator 전환 + Meta 앱 생성, 토큰은 .env로 전달 (2026-11-03)
- 이미 있는 계정을 쓰는지, 새로 만드는지. Business/Creator 전환과 Meta 개발자 앱 생성은 사용자 계정으로만 가능하므로 **사용자가 직접** 해야 한다(08 문서 §계정 세팅). 토큰은 `.env`로만 전달.

## 10. 날씨 기능 (위치 권한) — ✅ 확정: 월페이퍼 모드에서만 기본 ON(선택), 모바일 기본 OFF (2026-11-03)
- 권장: 월페이퍼 모드에서만 기본 ON(선택), 모바일은 OFF 기본. 위치 권한 요청이 스토어 심사·사용자 신뢰에 부담이면 전부 OFF로 출시.
