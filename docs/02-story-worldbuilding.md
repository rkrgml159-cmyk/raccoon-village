# 02. 세계관 & 스토리

## 톤
**"조용한 멸망 이후"** — 디스토피아지만 공포가 아니라 고요함. 인간은 없고, 인간이 남긴 것만 있다.
폭력·전투·질병 묘사 없음. 슬픔은 있되 따뜻하게. (힐링 기둥 유지)

## 배경 설정 (플레이어에게는 서서히 공개)
- 때: 인간이 사라진 지 수십 년 후. 정확한 연도는 밝히지 않는다. 게임 속 날짜는 **현실 날짜**를 그대로 쓴다(기둥 2). 즉 "지금 이 시각의 지구"다.
- 왜 사라졌나: 명시하지 않는다. 단서만 남긴다 — 녹슨 안내 방송, 멈춘 시계탑, "대피 안내" 포스터, 마지막 날짜가 적힌 달력. (플레이어가 해석하게 둔다)
- 자연은 회복 중. 도시 위로 나무가 자라고, 지하철 터널엔 물이 고여 우물이 됐다.
- **너구리들**은 인간이 버린 물건을 "아티팩트"라 부르며 쓰임새를 모른 채 사용한다(썬글라스를 모자처럼, 솜사탕 기계를 신전처럼). 이 오해가 스킨/아티팩트의 유머 소스.

## "만남의 공간" 설정 오류 해결
원래 메모: *"같은 지구인데 (다른 플레이어의 마을과) 만나는 건 설정 오류인가?"*

**해결: 모든 플레이어의 마을은 같은 폐허 도시 안의 서로 다른 '구역(區)'이다.**
- 도시는 거대했고, 구역 사이는 무너진 고가도로·범람한 강으로 끊겨 있다. 그래서 각 마을은 고립된 채 자기 구역을 가꾼다. → 플레이어별 마을이 독립적인 이유.
- 유일한 연결 통로는 **폐지하철 터널**. 모든 노선이 모이던 **옛 환승역**이 자연스럽게 너구리들의 **만남의 공간**이 됐다.
- 놀러가기 = 너구리가 터널을 타고 다른 구역에 가는 것. 화면 연출: 터널 입구로 들어감 → 로딩 → 상대 마을 터널 출구에서 나옴.
- 환승역 이름(가제): **"환승역 0번"** 또는 **"너굴역"**. 역 안에는 멈춘 전광판이 있고, 플레이어들이 남긴 짧은 메모(방명록)가 벽에 붙는다.
- **마을 이름 규칙: "<닉네임>의 디스토피아"**. 각 플레이어의 구역은 닉네임으로 불린다(예: "민지의 디스토피아"). 환승역 승강장 표지판에 "민지의 디스토피아 방면"처럼 표시되고, 방문 시 터널 출구 위 간판에 같은 이름이 뜬다. 인간이 남긴 역명판을 너구리들이 긁어내고 자기들끼리 부르는 이름을 새긴 것이라는 설정 → 닉네임이 폐허 위에 손글씨로 보인다.
- 이 설정이면 "같은 지구"가 오류가 아니라 오히려 **핵심 장치**가 된다: 모두가 같은 밤하늘, 같은 계절, 같은 날짜를 공유한다.

## 스토리 전달 방식 (설명 금지, 발견 위주)
1. **속마음(생각 풍선)**: 너구리 혼잣말에 세계관 단서를 섞는다. 예) "저 큰 돌(차)은 왜 안 움직일까." / "밤에 하늘이 깜빡이던 시절이 있었대."
2. **아티팩트 발굴**: 우물·나무·숨숨집을 지을 때 가끔 "오래된 물건"이 나온다. 도감에 들어가고, 도감 설명은 너구리 시점의 오해 + 플레이어만 알아챌 수 있는 진실.
3. **계절 이벤트**: 현실 기념일(설날, 추석, 할로윈, 크리스마스)마다 "인간들이 이맘때 뭘 했는지"를 너구리들이 흉내 내는 이벤트. 이것이 디스토피아 설정과 힐링을 잇는 장치.
4. **번역기 아티팩트(중반 핵심)**: 발굴하면 너굴어가 부분 해석된다. 처음엔 단어 하나("…밥?"), 나중엔 문장. 플레이어가 "알아듣게 되는" 성장이 곧 스토리 진행.
5. **환승역 전광판**: 챕터가 진행될 때마다 전광판에 글자가 한 줄씩 복구된다. 최종적으로 마지막 안내 방송 문구가 완성된다. (엔딩 아닌 "열린 마무리")

## 챕터 뼈대 (초안, 스토리 작가 세션에서 확장)
| 챕터 | 트리거 | 공개되는 것 |
|---|---|---|
| 0 서막 | 첫 실행 | 너구리 한 마리가 터널에서 나온다. 마을은 빈 터. |
| 1 정착 | 숨숨집 1개 완성 | 두 번째 너구리 합류. 첫 아티팩트(녹슨 숟가락). |
| 2 소리 | 우물 완성 | 물소리·바람소리 레이어 해금. 속마음에 "옛날 소리" 언급 시작. |
| 3 계절 | 첫 계절 변화 경험 | 달력 아티팩트. "날짜"의 의미를 너구리들이 궁금해함. |
| 4 번역기 | 아티팩트 10개 | 너굴어 부분 해석 해금. |
| 5 환승역 | 번역기 해금 후 | 만남의 공간 개방. 다른 마을 방문 가능. |
| 6+ 전광판 | 방문/교류 누적 | 전광판 한 줄씩 복구. |

## 금지 목록 (톤 유지용)
- 인간 시체·유골·전쟁 묘사 금지
- "바이러스/핵" 같은 직접 원인 명시 금지
- 너구리가 인간을 그리워하는 식의 감상 금지 (너구리는 인간을 모른다. 그래서 더 담담하다)
